## 🚀 Featured Projects

<details>
<summary><b>🏠 SmartNest — Owner-to-Buyer Property Listing Platform</b></summary>
<br/>

A full-stack real estate listing platform that eliminates broker dependency by connecting property owners directly with buyers. Built with a secure multi-role architecture and clean RESTful API design.

| Attribute | Detail |
|---|---|
| **Stack** | HTML · CSS · JavaScript · Node.js · Express.js · MongoDB · JWT |
| **Auth** | JWT-based role authentication (Owner / Buyer roles) |
| **Security** | bcrypt password hashing · protected route middleware |
| **Database** | MongoDB with Mongoose ODM · schema validation |
| **Deployment** | AWS EC2 (server) · AWS S3 (static assets) — in progress |
| **Status** | Active Development — Capstone Project |

SmartNest is architected around a clear separation of concerns: the Express.js backend handles all API logic and authentication middleware, MongoDB stores property listings and user data with referential integrity, and JWT tokens secure session state without server-side sessions. The project mirrors production engineering practices including environment variable management, API error handling, and modular route structuring.

</details>

<details>
<summary><b>🔧 YouTube Focus Mode — Chrome Extension</b></summary>
<br/>

A browser productivity extension that transforms YouTube into a distraction-free study environment with built-in time management.

| Attribute | Detail |
|---|---|
| **Stack** | HTML · CSS · JavaScript · Chrome Extension API |
| **Features** | Pomodoro timer · Smart video filter · Dark mode toggle · Browser notifications |
| **Distribution** | Chrome Extension (Manifest V3) |
| **Use Case** | Student productivity · Focused learning sessions |

Built from scratch using the Chrome Extension API with a clean popup UI. The smart video filter hides recommended content and Shorts, keeping the user focused on intentional viewing. The Pomodoro integration sends native browser notifications at work/break intervals.

</details>
